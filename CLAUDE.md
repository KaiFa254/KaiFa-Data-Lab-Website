## Claude-specific notes

- Start large tasks in **plan mode**: investigate and propose; do not edit
  until the plan is approved.
- Ask before running any command that installs, deletes, deploys or
  contacts an outside service.
- When a task is done, list: files changed, commands run, test results,
  remaining risks.
